# ⚽ QUIZBALL

An interactive football quiz web application that challenges users with questions about clubs, players, competitions, and football history.

## Overview

QUIZBALL is a browser-based quiz game designed for football enthusiasts. Users can test their football knowledge through multiple-choice questions while keeping track of their score throughout the game.

The project was developed as a personal web development project with a focus on creating an engaging and responsive user experience.

## Features

* Football-themed quiz questions
* Multiple-choice answers
* Real-time score tracking
* Interactive user interface
* Responsive design for desktop and mobile devices
* Simple and intuitive navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript
